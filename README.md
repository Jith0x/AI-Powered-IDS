## Overall Learning 

During the SURE ProEd CyberSecurity & Ethical Hacking course, I developed an AI-Based Intrusion Detection System (IDS) for Industrial IoT (IIoT). The project helped me understand how cybersecurity concepts, machine learning, data preprocessing, and network traffic analysis can be combined to identify malicious activities.

I gained practical experience in handling cybersecurity datasets, preprocessing network traffic data, training machine-learning models, evaluating classification performance, and interpreting security-related results. The project also strengthened my skills in Python, Pandas, NumPy, Scikit-learn, XGBoost, data analysis, model evaluation, problem-solving, documentation, and cybersecurity fundamentals.

The project gave me practical exposure to applying Artificial Intelligence and Machine Learning techniques to a real-world cybersecurity problem rather than relying only on traditional rule-based detection methods.

The project focuses on developing an AI-based Intrusion Detection System capable of detecting and classifying malicious network traffic in Industrial IoT environments.

The system uses machine-learning techniques to analyze network traffic features and identify whether the traffic represents normal activity or a potential cyberattack.

The project was developed using the CIC-IIoT 2025 dataset, which contains network traffic representing different types of activities and attacks in Industrial IoT environments.
